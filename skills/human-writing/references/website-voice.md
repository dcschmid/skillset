# Site voice profile

`assets/website-voice.template.md` defines: base tone, language + variant,
address (Du/Sie, you), audience, domain vocabulary, rhythm, preferred
phrasings, banned phrasings, per-section profiles.

Legitimate drift: docs ≠ blog ≠ product page — profiles differ per section
BY DESIGN. Audit compares each page against its section profile; only drift
inside one section is a finding. Mixed Du/Sie within one section, or the
same concept under three names across sections, is worth reporting.
Multi-language sites: DE and EN evaluated against their own profiles;
tone may intentionally differ, terminology must map.
