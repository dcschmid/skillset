# React and Next.js examples

These files demonstrate individual patterns. They are snippets for an existing
project, not standalone runnable packages. Adapt them to the installed framework
version and run the target project's checks after integration.

| Directory | Demonstrates |
|---|---|
| [react-vite/](react-vite/) | Typed state, derived data, and effect cleanup |
| [nextjs-app-router/](nextjs-app-router/) | Page, layout, loading, and metadata responsibilities |
| [reusable-components/](reusable-components/) | Component variants and composition |
| [forms-validation/](forms-validation/) | useActionState with server-side validation |
| [testing-patterns/](testing-patterns/) | Component and browser test patterns |

The documented example baseline is React 19.3 / Next 16.4. Whether a pattern
fits your project depends on its installed versions. See
[version-policy.md](../references/version-policy.md) for the compatibility rules.

```text
Use react-nextjs. Add error states to our existing form. Consult the
forms-validation example, but check our framework version first and retain
the existing validation library.
```

Use the prompt in Claude Code, Codex, or oh-my-pi in the Working profile.
The [skill README](../README.md) explains installation.
