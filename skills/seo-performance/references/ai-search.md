# AI search / AEO / GEO — honest layer

Grounded in Google AI features + AI-optimization guidance (verified
2026-11-14). No special "AI schema", no llms.txt requirement, no GEO hacks.

## What actually helps generative retrieval (all overlap technical SEO)
- extractable answers: direct Q→A phrasing, definitions, lists, comparison
  tables in delivered HTML (many LLM crawlers don't run JS).
- clean semantics: headings answer structure, landmarks, breadcrumbs.
- entity consistency: org name/product names stable across pages + schema.
- trust: real author/company info, dates, cited sources.
- accessibility/indexability parity: same robots/canonical/abs-URL rules.
- structured data where content warrants (schema tiers unchanged).

## What is NOT required (do not fabricate obligations)
- llms.txt / ai.txt / markdown mirrors: optional extras, offer only with a
  stated project reason; zero official requirement to enter AI features.
- invented schema types; "AI-crawler-specific" meta tags.
- optimization to speculated internal LLM ranking factors = folklore.

## Assessment = same evidence + answer-clarity read
Report flags: thin-answer pages (question-heavy topics, answer in >500
prose words with no summary), missing TL;DR, entity drift, JS-only answers.
