# Audio pipeline (project-lifecycle view)

```
IMPORT → ANALYZE → GENERATE/PROCESS → QC → EXPORT → INTEGRATE → PLAYTEST → RELEASE
```

## Stage tools (all skill scripts, host Python+ffmpeg; gen via gaf)

| Stage | tool | writes |
|---|---|---|
| import | `audio_audit.py` facts | report only |
| analyze | `audio_batch.py report` | table |
| generate | `gaf_adapter.py` | copy into --out |
| process | `audio_process.py` / `audio_batch.py process` | new files |
| QC | `audio_validate.py --profile` | verdict |
| export | `audio_batch.py convert --to wav|ogg|flac|mp3|opus` | new files |
| integrate | `engine_defold.py` / `engine_godot.py` | engine files |
| release | `audio_manifest.py check` + `audio_validate.py` | report |

## Formats (engine truth, don't guess per platform)

WAV pcm_s16le: short SFX both engines. OGG: music/long loops — Godot
AudioStreamOggVorbis loop; Defold streams wav/ogg (`.sound stream:`).
FLAC/opus: archive/interchange; convert at export. Web/mobile: smaller
budgets (references/performance.md).

## Manifest (schema in templates/audio-manifest.json)

Every shipped asset: id, category, source+model, seed, measured
duration/rate/channels, license_status, quality_status, target_engine.
Generated by `audio_manifest.py create` (measures now) or `ingest` (from
gaf output dir); drift re-checked by `check` before release.

## Safety contract (all stages)

originals read-only · outputs unique-suffixed · dry-run supported · idempotent
(processed files skipped via sidecar) · rollback = remove generated files ·
every stage logs measured before/after. No silent overwrite anywhere, ever.
